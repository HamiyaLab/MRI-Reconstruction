
# MRI-Reconstruction

Reproducible implementations and experiments for Magnetic Resonance Imaging (MRI) reconstruction.

## Overview

This repository provides independent implementations of classical and
advanced MRI reconstruction algorithms, with an emphasis on mathematical
understanding, reproducibility, and engineering practice.

## Algorithms

### Parallel Imaging
- [ ] SENSE
- [ ] GRAPPA

### Iterative Reconstruction
- [ ] CG-SENSE

### Compressed Sensing
- [ ] TV-SENSE
- [ ] Wavelet-SENSE

### Low-Rank Reconstruction
- [ ] SAKE
- [ ] LORAKS

## Project Structure

```text
algorithms/       Algorithm implementations
datasets/         Dataset instructions and organization
docs/             Mathematical notes and documentation
examples/         Reproducible examples
tests/            Unit tests and validation
```

## Development Principles

- Independent implementations
- Clear mathematical explanations
- Reproducible experiments
- Unit testing and numerical validation
- No unauthorized clinical or proprietary data
